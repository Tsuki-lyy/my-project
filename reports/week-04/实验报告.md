### 3.2 类图 (Class Diagram)

文件：[docs/uml/class.puml](../../docs/uml/class.puml)

```plantuml
@startuml class
skinparam classAttributeIconSize 0

class Database {
  - executor: Box<Executor>
  + new_in_memory() Result<Database>
  + execute(sql: &str) Result<Vec<Vec<Value>>>
}

class Parser {
  - tokens: Vec<Token>
  - pos: usize
  + new(sql: &str) Parser
  + parse() Result<Statement>
}

class Lexer {
  - input: &[u8]
  - pos: usize
  + new(input: &str) Lexer
  + tokenize() Result<Vec<Token>>
}

class Planner {
  + new() Planner
  + plan(stmt: Statement) Result<PhysicalPlan>
}

class Executor {
  - storage: Box<dyn StorageEngine>
  - catalog: Box<Catalog>
  + new(s, c) Executor
  + execute(plan) Result
}

interface StorageEngine {
  + create_table()
  + drop_table()
  + insert()
  + scan()
  + update()
  + delete()
}

class MemoryStorage {
  - tables: RwLock<HashMap>
}

class Catalog {
  - tables: RwLock<HashMap>
  + create_table()
  + drop_table()
  + table() Option
}

enum Statement <<enumeration>> {
  CreateTable
  DropTable
  Insert
  Select
  Update
  Delete
}

Database --> Executor
Database ..> Parser
Database ..> Planner
Parser ..> Lexer
Parser ..> Statement
Planner ..> Statement
Executor --> StorageEngine
Executor --> Catalog
StorageEngine <|.. MemoryStorage
@enduml
```

:submit SQL;
|Database|
:Lexer.tokenize;
if (tokenize ok?) then (yes)
  :Parser.parse;
  if (parse ok?) then (yes)
    :Planner.plan;
    if (plan ok?) then (yes)
      :Executor.execute;
      :return result;
    else (no)
      :return SemanticError;
    endif
  else (no)
    :return ParseError;
  endif
else (no)
  :return LexError;
endif

## 5. 工具使用心得

### 5.1 PlantUML vs Mermaid

| 维度 | PlantUML | Mermaid |
|------|----------|---------|
| 表达力 | 强（支持全部 14 种图） | 中（9 种） |
| 嵌入 MD | 需代码块 + 渲染器 | 原生支持 |
| 维护成本 | 高（独立 .puml 文件） | 低（直接写在 .md） |
| 本项目 | 标准 UML 物 | 报告插图 |

**结论**：本项目采用 **Mermaid 内嵌 + PlantUML 沉淀** 双轨制——报告里用 Mermaid 即看即得，工程档案用 PlantUML 严格建模。

### 5.2 渲染验证

- PlantUML 渲染：在 VS Code / TRAE 装 `plantuml` 扩展，右键 "Preview"
- Mermaid 渲染：TRAE / GitHub 原生支持
